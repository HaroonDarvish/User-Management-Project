# User Management System

A modern and responsive **User Management System** built with **HTML, CSS, and JavaScript**. This project demonstrates how JavaScript can be used to create a dynamic and interactive web application for managing user data.

## 🌐 Live Demo

👉 **[Visit the Website](https://haroondarvish.github.io/User-Management-Project/)**

The application allows users to **add, edit, remove, and search users dynamically** without reloading the page. It also includes user statistics and filtering functionality.

## ✨ Features

* ➕ Add new users
* ✏️ Edit existing users
* 🗑️ Remove users
* 🔍 Search users by name
* 📍 Find users by city
* 📊 Display user statistics
* 🔄 Dynamically update the user list
* 📱 Fully responsive design
* ⚡ Built with vanilla JavaScript
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Dynamic functionality and user management

## 🎯 Project Purpose

The main purpose of this project is to practice and demonstrate important JavaScript concepts such as **arrays, objects, functions, array methods, DOM manipulation, event handling, searching, updating, and dynamically rendering content**.

This project is part of my journey to improve my **front-end web development and JavaScript skills**.
